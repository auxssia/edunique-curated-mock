# EduNique Home: curated playful mock

A design mock of the EduNique Home page, built only from the current site's copy, photos and videos. It shows the page as one curated story (Understand, Learn, Apply, with Aura as the guide) with GSAP motion.

Open `index.html`. Press "Show design notes" (bottom right) to see why each choice was made.

Links to products, categories and the curriculum PDFs point at the private staging site and will not open from here.
